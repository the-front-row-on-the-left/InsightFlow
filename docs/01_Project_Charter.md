# Project Charter - AI Ops Platform

## 1. 프로젝트 한 줄 정의

기업이 다양한 AI 서비스를 탐색·실행·조합하고, 그 과정에서 발생하는 비용·정책·리스크를 통제할 수 있는 **AI 서비스 플랫폼 + AI Ops Platform**을 구축한다.

## 2. 문제 정의

기업의 AI 도입 문제는 단순한 모델 성능보다 운영에서 크게 드러난다.

- 사용량 급증에 따른 비용 통제 실패
- 팀/사용자별 사용량과 비용 가시성 부족
- 고비용 모델 무분별 사용
- 과도 호출로 인한 장애 및 API 남용
- 예산 초과와 비용 예측 불가

## 3. 목표

### Product Goals
- AI 서비스를 상품처럼 탐색/선택할 수 있게 한다.
- AI 서비스를 조합 가능한 Workflow로 만든다.
- 조직 단위 정책/예산/모델 제한을 적용 가능하게 한다.
- 사용량/비용/리스크를 추적하고 설명 가능하게 만든다.
- 더 저렴한 대체 모델/서비스/조합을 추천한다.

### MVP Goals
- 서비스 카탈로그 조회
- 단일 AI 실행 및 간단한 Workflow 실행
- API Gateway를 통한 요청 통제
- Usage / Billing 기본 집계
- 기본 Policy / Rate Limit 적용
- 추천 1종 이상 제공
  - 서비스 추천 또는 비용 최적화 추천 중 1개

## 4. 범위

### In Scope
- 내부 AI 서비스 카탈로그
- 외부 AI API 연동(OpenAI 계열 가정)
- API Gateway 기반 통제
- 비용/사용량 집계
- 기본 정책 엔진
- 팀/사용자 기준 제한
- 결과 저장 및 재사용

### Out of Scope (MVP)
- 외부 파트너 온보딩 포털
- 복잡한 drag-and-drop Workflow editor
- 실시간 스트리밍 응답 최적화
- 조직별 복잡한 과금 정산
- 멀티 리전 / 멀티 테넌시 정식 지원
- 정식 인증/인가 체계(JWT/OAuth2/RBAC)

## 5. 성공 기준

- 요청별 사용량 추적률 100%
- 정책 검사 누락 0건
- 비용 집계와 실제 API 사용량 오차 ±5% 이내
- 팀/사용자 기준 비용 조회 가능
- Workflow 1종 이상 저장 및 재실행 가능
- 비용 최적화 추천 PoC 동작

## 6. 주요 이해관계자

| 역할 | 기대 가치 |
|------|-----------|
| CFO | 비용 통제, 예산 예측 |
| CTO | 안정성, 운영 표준화 |
| DevOps | 관측성, 알림, 장애 예방 |
| 팀 리더 | 팀별 비용/정책 분리 |
| Biz/분석가 | AI 활용, 보고서 자동화 |
| 기획자 | 빠른 PoC, 서비스 조합 실험 |
